# Общее описание задачи 

Создать LLM-агента на основе gpt4.1, подключенного через openRouter.
Задаче агента - написать код создания презентации с помощью python-pptx.
Задание для презентации передается в виде текстового файла.
Код создается в папке .generated.
Затем код запускается, если есть ошибки - исправляется.
Презентация создается в папке .output.

Python установлен в .venv
Ключ к openRounter есть в .env (и environment)

Входные данные:
- задание в виде текстового файла

Выходные - код создания презентации
