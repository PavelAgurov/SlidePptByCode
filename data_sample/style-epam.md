# EngX Brand Style Guide - Color Palette

## Overview

EngX color palette inspired by the EPAM Continuum Colors. The palette is designed to be recognizable to users and clients while maintaining consistency across all internal EngX products.

## Primary Palette

Primary brand colors used to provide consistency throughout all brand communications. White and Aqua Squeeze are used predominantly for backgrounds. Elf Green should be used thoughtfully and with meaning - never in large blocks.

### White

- **RGB:** 255, 255, 255
- **CMYK:** 0, 0, 0, 0

### Aqua Squeeze
- **HEX:** #76CCBE

## Usage Guidelines

### Color Proportions
Important to follow proportion rules when creating brand communications to maintain consistency and accessibility.

### Color Guidance - DO NOT:

- ❌ Use light backgrounds with white text
- ❌ Use Secondary Palette as backgrounds (except Navy)
- ❌ Mix Navy color with Thunder
- ❌ Use colored text if it's not a link
- ❌ Use color overlays on imagery
- ❌ Use Deep Saffron or Elf Green in illustrations
